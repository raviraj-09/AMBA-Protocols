# AMBA Protocol

## Overview

This project focuses on the **design and verification of the AMBA (Advanced Microcontroller Bus Architecture) protocol**.

The project aims to understand AMBA bus communication, protocol behavior, RTL implementation, and functional verification through simulation and testing.

## Objectives

* Understand AMBA protocol fundamentals
* Implement a basic AMBA-based design
* Verify protocol functionality
* Test different read and write transactions
* Check data integrity and protocol behavior
* Analyze simulation results and waveforms

## Key Features

* AMBA protocol implementation
* Read and write transaction verification
* Functional correctness checking
* Simulation-based verification
* Waveform analysis
* Scalable verification environment

## Verification

The design can be verified using different verification methodologies and tools, including **SystemVerilog-based or UVM-based verification environments**.

## Tools & Technologies

* Verilog / SystemVerilog
* UVM
* QuestaSim / ModelSim
* Icarus Verilog
* GTKWave
